CalendarApp GUI usage

- Start by double clicking CalendarApp.jar or run java -jar CalendarApp.jar
- Default calendar loads in system timezone
- View schedule use the date picker and click refresh to see up to 10 events
- Create event click New Event fill subject start date time and end date time use date picker and time spinner then click save
- Create all day event check All Day option then pick date then save
- Switch calendar open Calendar menu select Switch Calendar then choose existing or Create New then enter name and timezone then confirm
- Edit event select event in table click Edit modify fields then click save
- Delete event select event in table click Delete then confirm
- Interactive mode run java -jar CalendarApp.jar --mode interactive and enter commands
- Headless mode run java -jar CalendarApp.jar --mode headless scripts/script.txt then program exits
