Calendar Application

A Java-based calendar application implemented using the MVC architecture.

Project Overview

This project implements a calendar system with a clear separation of Model, View, and Controller. It was developed as part of a coursework project focusing on object-oriented design, abstraction, and test-driven development.

Project Structure

  • model/ – Core data structures and business logic
  • controller/ – Application control flow
  • view/ – User-facing components
  • test/ – Unit tests

How to Run

Compile and run the application using: 

javac CalendarApp.java
java CalendarApp

See USEME.md for detailed instructions.
